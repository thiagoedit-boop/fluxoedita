# FluxoEDITÁ

App de criação de conteúdo do Thiago Editá: blocos (YouTube, Instagram, finanças, listas), vídeos com roteiro, gravação e edição, e mesa livre estilo Milanote.

- Funciona offline (PWA): no iPhone, abra no Safari e use **Compartilhar › Adicionar à Tela de Início**.
- Os dados ficam só no aparelho e no repositório privado `fluxoedita-dados`. Este repositório tem apenas o código do app.
- Fonte Unbounded sob a SIL Open Font License (`fonts/OFL.txt`).
